# Enterprise Data Warehouse Migration Using Agile Scrum and Jira

## Project Overview

This project demonstrates the planning and management of an Enterprise Data Warehouse Migration using Agile Scrum methodology in Jira.

The objective was to migrate data from legacy reporting systems to a centralized data warehouse while ensuring data quality, stakeholder collaboration, and project transparency throughout the project lifecycle.

The project was managed using Jira Scrum Boards, Epics, User Stories, Sprint Planning, Sprint Tracking, and Agile delivery practices.

---

## Objectives

- Assess existing data sources and reporting requirements
- Design the target data warehouse architecture
- Develop ETL pipelines for data migration
- Validate migrated data and business reports
- Deploy the data warehouse solution
- Track project progress using Agile Scrum practices

## Project Structure

### Epic 1: Project Planning & Assessment

- Identify Existing Data Sources
- Gather Business Requirements
- Assess Data Quality Issues

### Epic 2: Data Mapping & Design

- Map Source Tables
- Design Warehouse Schema
- Approve Data Model

### Epic 3: ETL Development

- Build Extraction Pipeline
- Transform Source Data
- Load Data Into Warehouse

### Epic 4: Data Validation

- Validate Migrated Data
- Verify Business Reports
- Resolve Data Issues

### Epic 5: Deployment

- Deploy Data Warehouse
- Conduct User Training
- Project Sign-Off
